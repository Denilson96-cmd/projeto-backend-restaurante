# Projeto Backend Restaurante

API REST de gerenciamento de pedidos desenvolvida com Spring Boot.

---

## 🚀 Tecnologias

- Java
- Spring Boot
- Spring Security
- JPA / Hibernate
- H2 Database
- Maven

---

## 📋 Requisitos

- Java 17+
- Maven
- Postman (para testes)

---

## ⚙️ Como executar o projeto

1. Clonar o repositório:
git clone https://github.com/Denilson96-cmd/projeto-backend-restaurante.git


2. Entrar na pasta do projeto:
cd projeto-backend-restaurante


3. Rodar o projeto:
mvn spring-boot:run

---

## 🌐 Acessando a API

A API roda localmente em:
http://localhost:8080

---

## 📄 Swagger (Documentação da API)

Acesse no navegador:
http://localhost:8080/swagger-ui.html
ou
http://localhost:8080/swagger-ui/index.html

---

## 🧪 Testes com Postman

- A coleção está disponível no repositório:
API-Restaurante.postman_collection.json

- Importar no Postman e executar os endpoints.

---

## 🔐 Autenticação

- A API utiliza autenticação via token (JWT)
- Algumas rotas são protegidas

---

## 🗄️ Banco de dados

- Banco utilizado: H2 (em memória)
- Acesso ao console:
http://localhost:8080/h2-console

---

## 📌 Funcionalidades

- Cadastro de usuários
- Login com autenticação
- Geração de token
- CRUD de pedidos
- Rotas protegidas

---
