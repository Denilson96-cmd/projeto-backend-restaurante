# Projeto Backend Restaurante

API REST de gerenciamento de pedidos desenvolvida com Spring Boot.

## Tecnologias
- Java
- Spring Boot
- JPA / Hibernate
- H2 Database

## Funcionalidades
- Cadastro de usuários
- Autenticação com token
- CRUD de pedidos

## Como rodar
1. Rodar a aplicação
2. Acessar via Postman
